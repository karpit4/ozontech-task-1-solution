# Демо измерения габаритов объекта на конвейере

[English version](README.md)

Демо алгоритма измерения габаритов объектов на конвейере:

`RGB-D point cloud -> удаление плоскости конвейера -> фильтрация выбросов -> convex hull -> minimum-volume OBB -> поправки размеров -> L/W/H -> проверка качества`

## Что умеет demo

1. Генерирует синтетические 3D-объекты: `box`, `cylinder`, `bottle`, `sphere`, `pencil`.
2. Имитирует шум depth-сенсора, конвейер и случайные выбросы.
3. Удаляет плоскость конвейера через RANSAC.
4. Удаляет выбросы адаптивным radius-фильтром и statistical filtering (SOR).
5. Строит convex hull и минимальный OBB.
6. Применяет постоянные поправки к измеренным высоте, длине и ширине.
7. Сравнивает результат с ground truth.
8. Проверяет допуск `max(5%, 5 mm)` по каждому размеру.
9. Рисует point cloud, OBB и отчёт об измерении.
10. Позволяет проводить benchmark для объектов разных размеров и форм.

## Структура проекта

```text
src/
├── demo.py            — точка входа, запуск демонстрации
├── scene.py           — синтетическая сцена: конвейер, объект, выбросы
├── objects.py         — генерация 3D-объектов
├── pipeline.py        — основной алгоритм измерения
├── evaluation.py      — оценка точности измерений
├── visualization.py   — визуализация point cloud, OBB и отчёта
├── benchmark.py       — benchmark точности и скорости
├── config.py          — параметры
└── __init__.py        — определяет src как Python-пакет
```

## Установка

```bash
python -m venv .venv

# Linux/macOS:
source .venv/bin/activate

# Windows:
# .venv\Scripts\activate

pip install -r requirements.txt
```

## Запуск

Запуск демонстрации:

```bash
python -m src.demo
```

Визуализация с отчётом об измерении сохраняется в:

```text
output/dimensioning_result.png
```

Запуск benchmark:

```bash
python -m src.benchmark
```

Для каждой формы benchmark измеряет `N_SIZES` кубов размером от 10 до 400 мм. Он выводит ошибки по каждому объекту и по каждой форме, время (P50 / P95 / max) и число пройденных объектов.

## Конфигурация

Все параметры лежат в `src/config.py`:

- объект для демо: `object_shape`, `object_dims`, `object_yaw`;
- модель сенсора: `depth_noise_std_mm`, `outlier_points`;
- фильтрация: размер вокселя, параметры RANSAC, radius-фильтра и SOR;
- поправки: `height_correction_mm`, `length_correction_mm`, `width_correction_mm` (прибавляются к измеренному значению, отрицательное число уменьшает его);
- `seed` делает генерируемую сцену воспроизводимой.

## Замечания

- Сцена синтетическая. Константы поправок подобраны экспериментально на ней и для реального сенсора требуют повторной настройки.
- Облако точек одинаково при каждом запуске, но шаги Open3D (RANSAC, OBB) могут давать слегка разные измерения от запуска к запуску.
